# Project requirements

- ASCII only in project-owned source, documentation, templates, examples and output
  labels. Use plain punctuation and status words, never emoji or typographic symbols.
- Preserve scanned source evidence and user data verbatim. This requirement does not
  authorize modifying other repositories or transliterating external command output.
- Run the ASCII guard and skill-frontmatter tests when changing documentation.
- Framework detection must distinguish static discovery from runtime verification.
  Document unsupported conventions; do not infer a public route from an unresolved mount.
- Keep runtime dependencies at zero. Use fixture tests for scanner changes.
- Keep historical release artifacts immutable; ship source changes in a new version.
